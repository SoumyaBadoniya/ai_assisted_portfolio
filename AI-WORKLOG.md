## 9. AI vocabulary used in this project

- **Generative AI:** A system that generates content, such as text, code, or images.
- **AI assistant:** A tool that responds to requests and supports tasks.
- **Agentic AI:** A system that can work toward a goal through multi-step actions, often using tools and checking results. A single code-generation prompt alone does not automatically make a workflow agentic.
- **Prompt iteration:** Revising instructions based on the output and evaluation.
- **Human review:** Checking generated work, making design decisions, and verifying behavior before submission.
